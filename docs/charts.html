Traefik log backends

Two traefiks ship their access logs through fluent-bit into one backend at a time; both traefiks are loaded at the same rate, so 2000 rps per traefik is 4000 log lines a second (~6.4 MB/s of json). Each point is the average over minutes 2–15 of a 15 minute step; memory is the peak working set of every container in the backend stack (grafana counts for loki, kibana for elk, minio/nats/postgres for the clusters).
